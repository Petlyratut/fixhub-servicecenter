# FixHub — заявки на запчасти для сервисного центра

Веб-приложение для сервисного центра по ремонту цифровой техники: свой каталог деталей с ценами, заявки на закупку запчастей, статусы, история изменений, регистрация сотрудников и админ-панель. Интерфейс — тёмная тема, работает на ПК и телефоне.

## Запуск (Windows / macOS / Linux)

1. Установите **Node.js 24 LTS** с https://nodejs.org (минимум 22.13). Других зависимостей нет — `npm install` не нужен.
2. Распакуйте архив и запустите:
   - Windows: двойной клик по `start.bat`
   - macOS / Linux: `./start.sh` или `npm start`
3. Откройте http://localhost:3000
4. **Первый зарегистрированный пользователь автоматически становится администратором.** Остальные после регистрации ждут подтверждения админом (раздел «Сотрудники»).

Чтобы открыть с других компьютеров в сети сервиса: `http://IP-компьютера:3000` (разрешите порт в брандмауэре).

## Роли
| Роль | Возможности |
|---|---|
| Мастер | Оформляет заявки, видит только свои, может отменить свою новую заявку, оставлять комментарии |
| Менеджер закупок | Видит все заявки, меняет статусы, ведёт каталог, экспорт в CSV |
| Администратор | Всё выше + подтверждение/блокировка сотрудников, роли, сброс паролей, удаление заявок |

## Статусы заявки
Новая → В обработке → Заказано у поставщика → Куплено → Получено на склад → Выполнено (выдано мастеру), а также «Отменено». Каждое изменение сохраняется в истории: кто, когда, комментарий.

## Возможности
- Регистрация и вход (пароли хешируются scrypt, сессии в HttpOnly-cookie, защита от перебора пароля)
- Каталог: название, артикул, категория, бренд, совместимые устройства, поставщик, цена закупки, цена для клиента, наличие; импорт из CSV (Excel)
- Заявка: детали из каталога или вручную, количество, устройство, № квитанции, приоритет, комментарий; сумма считается автоматически, цены фиксируются на момент заявки
- В списке видно, кто и когда оформил заявку; фильтры по статусу, датам, поиску; смена статуса прямо в таблице
- Печать заявки, экспорт списка в CSV для Excel
- Дашборд: количество по статусам, суммы за месяц и по активным заявкам

## Данные и резервная копия
Вся база — один файл `data/service.db`. Для бэкапа просто копируйте его (лучше при остановленном сервере).

## Настройки (переменные окружения)
- `PORT` — порт (по умолчанию 3000)
- `DATA_DIR` — папка для базы
- `SECURE_COOKIE=1` — при работе через HTTPS (например, за nginx)

## Размещение в интернете
Запустите на VPS (Ubuntu): установите Node.js 24, скопируйте папку, запустите через `pm2 start server.js --node-args="--no-warnings"` и поставьте nginx с HTTPS (Let's Encrypt) перед приложением, затем включите `SECURE_COOKIE=1`.
